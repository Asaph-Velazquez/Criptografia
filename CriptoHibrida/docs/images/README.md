# Capturas de Nexo

Guarda aquí las capturas que aparecen en el README principal. Cada SVG actual es un marcador de posición visible. Sustitúyelo por una captura PNG o WebP y cambia la extensión correspondiente en el README principal.

| Archivo | Contenido recomendado | Tamaño sugerido |
| --- | --- | --- |
| `transferencia.png` | Pantalla inicial de envío o recepción de archivos. | 1440 × 900 px |
| `llaves.png` | Pantalla de generación y gestión de llaves. | 1440 × 900 px |
| `acerca-de.png` | Página Acerca de con los créditos y la animación. | 1440 × 900 px |
| `verificacion.png` | Resultado de recuperación con firma verificada. | 1440 × 900 px |

Usa PNG o WebP, elimina datos personales y no incluyas llaves privadas, respaldos ni contenido sensible en las imágenes.
